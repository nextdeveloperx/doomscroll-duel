# Play Console: content rating questionnaire (IARC)

Where: Play Console > Policy and programs > App content > Content rating. Answer for the app as it ships. Answers go to
IARC, which assigns ratings for each region (ESRB, PEGI, IARC Generic, India's rating via IARC).

**Category:** "All other app types" (utility, productivity, communication or other). It is not a game of chance and not a social network, but it has user interaction, so answer those questions honestly.

| Question | Answer | Why |
|---|---|---|
| Violence (realistic or cartoon, any depiction) | **No** | The brain cartoon gets "fried" or turns into a friendly zombie. No injury, blood or weapons. If the questionnaire asks specifically about "cartoon or fantasy violence", the honest answer is still No: nothing is attacked or hurt |
| Blood and gore | No | |
| Sexual content or nudity | No | Dare proofs must follow the Terms (no sexual content) |
| Profanity or crude humour | No | Dares and roast stickers are fixed, mild, and written by us |
| Fear / horror | No | |
| Drugs, alcohol, tobacco (use or references) | No | |
| Gambling or simulated gambling | **No** | There is no money, no chance element and no casino game. Winning depends only on how many reels you watch. Coins are virtual, cannot be bought and cannot be cashed out |
| Contests/ challenges with real prizes | No | |
| Do users interact or exchange content? | **Yes** | Friends can challenge each other, see each other's reel counts, send preset roast stickers, and optionally send a photo or video as dare proof (private between two people, deleted after 7 days) |
| Is there moderation / reporting for user content? | **Yes** | Report and block (see the checklist: these screens must be built before launch) |
| Does the app share the user's location with others? | No | |
| Does the app share personal information with other users? | **Yes, limited** | Username and display name are visible to friends and challenge opponents |
| Digital purchases | **Yes** | Pro subscription |
| Unrestricted internet access / web browsing | No | |
| Is the app directed at children? | **No** | Target age 16 and above (see the Privacy Policy) |

Expected outcome: a low-to-medium rating (for example IARC 12+/Teen, mostly because users interact and there are
in-app purchases). Do not try to hide the interaction or the purchases to get a lower rating: Google can change the rating
after review.

**Target audience and content (a separate form):** choose age groups **16-17 and 18+** (or only 18+, see the age note in
`review-checklist.md`). Do not select any group under 13. The app must not use cartoon characters in a way aimed at
children; the brain character is a friendly mascot for teens and adults, so keep the store art mature enough.
